Upload to your library

Your audio file is sent to your private Cloudflare Worker, which stores it in your public GitHub music library.

The Worker URL and upload key are kept only in this page while it is open. They are not saved to the repository, local storage, or cookies. Generate a strong key here, then add that exact value as a Secret named UPLOAD_KEY in Cloudflare. Save it in your password manager so you can use it here later.
